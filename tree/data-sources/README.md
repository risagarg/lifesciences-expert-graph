### Contents (6)
- [NPPES NPI registry](nppes.md) — Backbone for US clinicians - NPI, taxonomy and practice location. Full file monthly, incremental updates weekly. Self-reported and says little about expertise.
- [Medicare Part D prescribers](medicare-part-d-prescribers.md) — One row per prescriber per drug per year, back to 2013. Medicare beneficiaries only, and published with a lag of about 18 months. Check the catalog for the latest year.
- [Open Payments](open-payments.md) — Industry payments to clinicians and teaching hospitals, in General, Research and Ownership files. Program year 2025 has 17.07 million records totaling $14.67 billion. Shows paid ties, not competence.
- [ClinicalTrials.gov](clinicaltrials-gov.md) — Trials, sponsors, sites and named study officials with affiliations, via API v2 or the AACT database. Sponsor-entered, so completeness varies.
- [FDA BMIS](fda-bmis.md) — Clinical investigators, CROs and IRBs named on Forms 1571 and 1572 received by CDER since October 1, 2008. Updated quarterly. Repeats an entity once per submission and is not comprehensive.
- [OpenAlex](openalex.md) — Publications, authors, institutions and funders. API keys and usage-based pricing since February 2026. ORCID is one of six disambiguation signals and the strongest when present.
